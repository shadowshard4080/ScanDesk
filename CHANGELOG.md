# Changelog

## 0.1.0 — 2026-11-17

First release.

- Multi-page scanning through SANE, saved as a single PDF at true page size
- **Enter** scans a page, **Esc** cancels the scan
- Import images, multi-page TIFFs and PDFs as pages (file dialog or drag & drop)
- Print pages and print files through CUPS, with a *Sides* setting for two-sided printing
- Copy mode (**Ctrl+Enter**): scan and print right away, with a copy count, black & white option and printer choice
- Menu bar, About dialog and `--version`
